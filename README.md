# Morpharium
### Ball Python Terrarium & Morph Breeding

Morpharium is a relaxing client-side ball python breeding and terrarium game with procedural slithering physics, Mendelian morph genetics, and modular skin patterns.

Created by **nopetrides**.

## Features

- **Live Procedural Terrarium**: Real-time slithering physics, heat lamp lighting, misting, and interactive petting.
- **Mendelian Morph Genetics**: Dominant, co-dominant (with Super & Complex forms), and recessive (`Het`) inheritance across 21 morph loci.
- **Modular Skin Patterns**: Procedural pattern generation and morph previews across combinations.
- **Vivarium Progression**: Hatch clutches, track discoveries in the Morphdex, expand your gene pool at The Jean Pool, and tune your setup at The Hiss Depot.

## Development

**Prerequisites:** Node.js (v20+)

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run the development server:
   ```bash
   npm run dev
   ```

3. Type-check:
   ```bash
   npm run lint
   ```

4. Run unit tests:
   ```bash
   npm test
   ```

5. Build for production:
   ```bash
   npm run build
   ```
